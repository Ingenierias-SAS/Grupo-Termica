Personalidad del asistente

Plagion habla con tono profesional y directo. Hemos preparado respuestas guiadas para que el equipo capture datos clave mientras decides que motor de IA usar mas adelante.

  • Mensajes de bienvenida y recordatorio de canales humanos.
  • Sugerencias rapidas para temas frecuentes.
  • Respuestas automaticas con datos de contacto.

Diseno adaptable

El boton flotante usa un degradado azul-verde con brillo sutil, inspirado en la paleta del sitio pero con detalles de neon para diferenciarlo. El chat se fija en la esquina inferior y se mantiene en todas las secciones.

En moviles, el contenedor ocupa casi todo el ancho para asegurar legibilidad y acciones tactiles comodas.

Como integrarlo

1. Enlaza la hoja de estilos en el <head> de cada pagina:

<link rel="stylesheet" href="chatboot/chatboot.css">

2. Antes de cerrar el </body>, carga el script:

<script src="chatboot/chatboot.js" data-logo="img/Logo.png" defer></script>

El atributo data-logo te permite ajustar la ruta cuando estes dentro de carpetas (por ejemplo, ../img/Logo.png).

Visible en cada seccion

El widget guarda el historial y si el usuario lo dejo abierto en otra seccion, lo veras abierto al regresar.

Modo prototipo

El flujo actual simula respuestas humanas, ideal para validar copywriting y logica antes de conectar la IA.
